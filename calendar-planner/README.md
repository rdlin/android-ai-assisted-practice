# Calendar Planner Practice

Standalone Android starter project for the Calendar Day Planner exercise.

- Prompt: `app/src/main/java/com/example/myapplication/practice/calendar/problem.md`
- Hints: `app/src/main/java/com/example/myapplication/practice/calendar/hints.md`
- Starter screen: `app/src/main/java/com/example/myapplication/practice/calendar/CalendarPlannerPracticeScreen.kt`

Run checks:

```bash
./gradlew test
```
