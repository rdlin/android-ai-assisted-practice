# Receipt Review Practice

Standalone Android starter project for the Receipt Review exercise.

Open this `receipt-review` directory directly in Android Studio.

- Prompt: `app/src/main/java/com/example/myapplication/practice/expenses/problem.md`
- Hints: `../hints/receipt-review-hints.md`
- Starter screen: `app/src/main/java/com/example/myapplication/practice/expenses/ReceiptReviewPracticeScreen.kt`
- Application ID: `com.example.receiptreviewpractice`

Run checks:

```bash
./gradlew test
```
