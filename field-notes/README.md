# Field Notes Practice

Standalone Android starter project for the Offline Field Notes exercise.

- Prompt: `app/src/main/java/com/example/myapplication/practice/fieldnotes/problem.md`
- Hints: `app/src/main/java/com/example/myapplication/practice/fieldnotes/hints.md`
- Starter screen: `app/src/main/java/com/example/myapplication/practice/fieldnotes/FieldNotesPracticeScreen.kt`

Run checks:

```bash
./gradlew test
```
